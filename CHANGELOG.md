## Update Policy

- Follow [Semantic Versioning](https://semver.org/) for version numbers.
- Add new release notes only to the target version file (for example `changelog/CHANGELOG-1.0.7.md`).
- Use change-type subsections (`Added`, `Changed`, `Fixed`, `Removed`, `Documentation`, `Improved`) under each version.
- When releasing a new version, add its file, move the previous latest into the archive list above, and update the Latest Version link in this index.
